<h1 id="firstHeading">About this reference</h1>

<div id="mw-content-text">

This site is the user-facing reference for the GTI language and standard
library, built as a clone of cppreference.com so that a reader arriving from
C++ already knows where everything is: headers list their classes and
functions, classes list their members by category, every member has its own
page with numbered declarations, and diagnostics have stable pages the
compiler can cite.

### What is generated, what is authored

- **Facts are generated.** Declarations, member lists, unit and class
  indexes, diagnostic codes, and the language sections are extracted from
  the repository at build time by `scripts/generate.mjs`. A generated fact
  cannot disagree with the compiler or standard library without the build
  noticing.
- **Evidence is verified.** Every runnable example is compiled and executed
  by the repository's own compiler during generation; the output shown is
  the real program's real output. Every diagnostic reproducer must fail
  with exactly the code its page documents.
- **Prose is authored** and validated: a description that names a member or
  function which does not exist in the shipped source fails the build.

The working record of the project — architecture, plans, decisions — stays
in `docs/` and is deliberately not published here. The normative language
text lives in `docs/language/` and is rendered by this site rather than
duplicated.

### Running locally

```sh
cd reference
pnpm install
pnpm dev        # http://localhost:3000, regenerates and verifies first
pnpm build      # static export to out/
```

Building the site requires a built compiler (`build/gti`, or `$GTI`); a
reference built without one could not honour its own guarantee.

### Contributing a page

1. Find the entity: its page already exists with generated declarations.
2. Add its description to `src/content/std-classes.ts`,
   `src/content/std-functions.ts`, or `src/content/diagnostics.ts`.
3. Add examples under `reference/examples/`; they are compiled and run at
   every build, and a snippet that cannot build does not ship.
