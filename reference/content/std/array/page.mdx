## Types

| Type | Description |
| --- | --- |
| [`std::array<T, N>`](/std/array/array/) | An exact `N`-element owner stored inline. |

The extent is part of the type. `std::array<int32_t, 3>` and
`std::array<int32_t, 4>` are distinct types, and no pointer decay is involved
in ordinary array operations.
