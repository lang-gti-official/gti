---
title: std::array::back
description: Borrows the final element of a non-empty array.
kind: member
since: 0.105.0
api:
  - std/array|method|std::array::back
examples:
  - update-last-element
---

Returns element `N - 1`, preserving receiver mutability. Calling `back()` when
`N` is zero follows the defined bounds-failure path.
