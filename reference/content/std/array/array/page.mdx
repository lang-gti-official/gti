`std::array<T, N>` owns exactly `N` inline elements. It performs no dynamic
allocation, and `size()` is the value-generic extent `N`.

Both `at()` and `operator[]` use GTI's checked fixed-array access. A mutable
receiver returns `mut T&`; a read-only receiver returns `T&`. The resulting
loan prevents conflicting access for its lifetime.

An exact contextual fixed array can initialize the owner:

```gti
std::array<int32_t, 3> values = std::array<int32_t, 3>({2, 4, 6});
```

Iteration is not part of the current class. `swap` is published as
declaration-only scaffolding and cannot yet be linked; every other operation
listed in the synopsis is implemented.
