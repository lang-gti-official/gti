---
title: std::array::swap
description: Reserved element-wise exchange operation that is not callable in native builds yet.
kind: member
since: 0.105.0
api:
  - std/array|method|std::array::swap
examples: []
---

This declaration is API scaffolding. GTI cannot yet move an owned value out
through a mutable reference, so the standard library cannot implement the
required element-wise exchange soundly. Calling `swap` currently reaches a
native link failure.

Use explicit construction or movement of whole arrays where the surrounding
ownership flow permits it. Do not treat this declaration as an implemented
operation until this page gains a verified example.
