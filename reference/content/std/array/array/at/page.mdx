---
title: std::array::at
description: Returns a checked element borrow for a signed or unsigned index.
kind: member
since: 0.27.0
api:
  - std/array|method|std::array::at
examples:
  - checked-access
---

`at(index)` accepts `int32_t` or `std::size_t`. The read-only overload returns
`T&`; the mutable receiver overload returns `mut T&`.

An out-of-range index follows GTI's defined bounds-failure path. It never
performs unchecked native indexing.
