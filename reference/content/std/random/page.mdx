```gti
#include <std/random>
```

`std::random_engine` is a deterministic xoshiro256++ engine seeded through
SplitMix64. Equal seeds produce equal sequences; this engine is suitable for
simulation and reproducible tests, not cryptographic use.

`std::random_device` obtains host entropy in bounded buffered reads. Calling it
returns `expected<uint32_t, int>` so an unavailable host entropy source remains
recoverable.
