---
title: std::print (std::string)
description: Writes a named or freshly constructed owning string without a trailing newline.
kind: function
since: 0.294.1
api:
  - std/string|function|std::print
examples:
  - print-owned-text
---

The borrowed overload reads a named `std::string&`. The owning overload
consumes a fresh or explicitly moved string, allowing an owned temporary to be
passed directly without binding a reference to temporary storage.

This page covers the `<std/string>` overloads. Prelude overloads handle
`std::string_view`, `char`, and fixed-width integers.
