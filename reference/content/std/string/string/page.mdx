`std::string` owns a dynamically sized sequence of characters. It is move-only:
ordinary copying is unavailable, and independent duplication is explicit
through `clone()`.

Construction and `append()` accept `std::string_view`, so literals can supply
text without becoming owners first. Mutable element access requires a mutable
receiver and returns a receiver-tied `mut char&`. Indexing is checked against
the logical string size.

Read-only iteration retains a checked loan of the backing storage. `view()`
returns a counted `std::string_view`, while `as_span()` returns a checked
character view. Both preserve the owner's lifetime and prevent movement or
mutation of the string while retained.

`swap` remains declaration-only scaffolding. All other members listed in the
synopsis are implemented.
