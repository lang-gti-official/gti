---
title: std::string::reserve
description: Ensures capacity for at least the requested number of characters.
kind: member
since: 0.36.0
api:
  - std/string|method|std::string::reserve
examples:
  - reserve-before-appending
---

`reserve(requested)` never changes logical size. Requests no larger than the
current capacity do not require growth. The exact growth policy is not API.
