---
title: std::string::at
description: Returns a checked character borrow for a signed or unsigned index.
kind: member
since: 0.36.0
api:
  - std/string|method|std::string::at
examples:
  - checked-character-access
---

Read-only receivers return `char&`; mutable receivers return `mut char&`.
Negative or out-of-range indices follow GTI's defined public bounds-failure
path rather than indexing native storage unchecked.
