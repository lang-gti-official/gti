---
title: std::string::operator!=
description: Reports whether an owning string and another owner or view differ.
kind: member
since: 0.36.0
api:
  - std/string|operator|std::string::operator!=
examples:
  - compare-different-text
---

This is the logical negation of character-wise equality and supports both
`std::string&` and `std::string_view` right operands.
