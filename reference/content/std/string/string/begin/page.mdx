---
title: std::string::begin
description: Creates a read-only character iterator retaining a checked loan of the string.
kind: member
since: 0.60.3
api:
  - std/string|method|std::string::begin
examples:
  - iterate-characters
---

The returned iterator owns its cursor and retains a shared dependency on the
string storage. Iterator copies have independent positions but keep the same
owner loan. Mutation and movement of the string are rejected while that loan
remains active.
