---
title: std::string::swap
description: Reserved ownership-exchange operation that is not callable in native builds yet.
kind: member
since: 0.105.0
api:
  - std/string|method|std::string::swap
examples: []
---

This declaration is API scaffolding. GTI cannot yet move an owner out through
a mutable reference, so the standard library cannot implement this exchange
without weakening the ownership model. Calling it currently fails during
native linking.

Move whole values through ordinary owning bindings where possible. Do not
treat this declaration as implemented until this page gains a verified
example.
