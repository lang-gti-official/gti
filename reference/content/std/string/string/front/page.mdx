---
title: std::string::front
description: Borrows the first character of a non-empty string.
kind: member
since: 0.105.0
api:
  - std/string|method|std::string::front
examples:
  - update-first-character
---

Returns character zero, preserving receiver mutability. Calling `front()` on
an empty string follows the defined bounds-failure path.
