---
title: std::string::operator[]
description: Returns a checked character borrow using subscript syntax.
kind: member
since: 0.36.0
api:
  - std/string|operator|std::string::operator[]
examples:
  - subscript-characters
---

Unlike C++, GTI's initial safe string subscript is checked against logical
size. Signed and unsigned index overloads preserve receiver mutability.
