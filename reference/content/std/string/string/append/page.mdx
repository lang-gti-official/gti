---
title: std::string::append
description: Appends every character from a string view to the end of the owner.
kind: member
since: 0.36.0
api:
  - std/string|method|std::string::append
examples:
  - append-text
---

`append(value)` grows capacity as needed and preserves the view's character
order. The receiver must be mutable. A view that aliases mutable receiver
storage is not part of the current public surface.
