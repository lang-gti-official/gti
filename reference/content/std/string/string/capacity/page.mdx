---
title: std::string::capacity
description: Reports the number of characters that fit before another allocation is required.
kind: member
since: 0.36.0
api:
  - std/string|method|std::string::capacity
examples:
  - reserve-capacity
---

Capacity is never smaller than size. Growth policy is an implementation detail;
callers should test only the guaranteed lower bound requested through
`reserve()`.
