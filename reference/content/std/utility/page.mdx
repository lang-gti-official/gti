```gti
#include <std/utility>
```

`std::pair<T, U>` stores two public values and moves constructor arguments into
their fields. `std::make_pair` returns the same explicit pair type without C++
deduction guides or implicit conversions.

`std::swap` and `std::exchange` are currently declaration-only and are absent
from the executable synopsis.
