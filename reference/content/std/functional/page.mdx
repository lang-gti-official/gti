```gti
#include <std/functional>
```

Each function object uses the corresponding exact operator on `T`. GTI does
not perform implicit conversion, overload ranking, reversed-operand lookup, or
argument-dependent lookup when the call operator is instantiated.

The generic `std::hash<T>` primary remains declaration-only and is not part of
the executable synopsis.
