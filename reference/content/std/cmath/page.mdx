```gti
#include <std/cmath>
```

Every declared operation is implemented for `float` (binary32). `double`
overloads and compile-time evaluation are not currently provided.

`floor` rounds downward, `ceil` upward, `trunc` toward zero, and `round` to
nearest with halfway cases away from zero. No integer conversion is involved,
so finite values outside integer ranges remain valid inputs. `abs` maps
negative zero to positive zero; the rounding functions preserve zero signs.

`sqrt` and `cbrt` compute roots, `pow` computes a power, and `fmod` returns
the remainder for a quotient truncated toward zero, with the numerator's sign.
`exp`, `log`, and `log10` provide exponentials and logarithms. Trigonometric
arguments and results use radians; `atan2(y, x)` accounts for the quadrant.

Invalid domains return NaN, poles and overflow return infinity, and underflow
returns a subnormal or signed zero. These are floating-point results, not GTI
checked failures. Use `isfinite`, `isinf`, and `isnan` to classify them.
Numerical approximations use the host math library and are not guaranteed
bit-identical across platforms. Native errno and floating exception flags are
not part of this API.
