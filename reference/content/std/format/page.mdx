```gti
#include <std/format>
```

`std::format` returns an owning string and `format_to` appends a complete
formatted result. They panic with a useful reason and caller location on error.
Choose `try_format` or `try_format_to` for `expected` results with `format_errc`.

Supported arguments include fixed-width integers, booleans, characters, both
floating widths, string views and transferred owning strings. Fields may be
automatic (`{}`) or numeric-indexed (`{0}`), with bounded alignment, width,
precision and presentation specifiers. `{{` and `}}` produce literal braces.
User-defined formatter customization and compile-time pattern checking remain
unsupported.

Formatted `print`/`println` have `try_print`/`try_println` siblings returning
`print_errc`, including stdout submission failure. Format errors produce no
partial output, although a host write failure can leave a prefix written.
Passing just one text argument to any print function writes it literally;
`format(pattern)` still interprets braces with no arguments. No output operation
implicitly flushes the host stream.
