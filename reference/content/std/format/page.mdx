```gti
#include <std/format>
```

The current formatter replaces sequential `{}` fields with fixed-width
integral arguments. `{{` and `}}` produce literal braces. Malformed braces or
an argument-count mismatch return `std::format_errc`; formatting does not
panic for those recoverable errors.

`std::format` returns an owning string. `try_print` and `try_println` format
first and write only after validation succeeds. Positional fields, format
specifiers, floating-point conversion, and user-defined formatter
customization are not implemented.
