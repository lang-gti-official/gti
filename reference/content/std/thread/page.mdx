```gti
#include <std/thread>
```

Thread programs require the concurrent execution profile. Direct compilation
uses `--execution-profile concurrent`; a project sets
`execution-profile = "concurrent"` in the selected profile.

`std::thread::start` consumes one transfer-safe exact `void()` task and returns
an owning worker. `std::thread_result<Result>` similarly transfers an owned
result through `join()`. References, borrowed captures, raw pointers, and
non-transferable captures or results are rejected before lowering.

Both owners are move-only and autojoin during destruction. Explicit `join()`
reports host failures through `std::thread_errc`; a GTI defined failure raised
by the worker is preserved and re-raised at the join boundary.
