```gti
#include <std/optional>
```

`std::optional<T>` owns either no value or one inline `T`. Empty construction
does not allocate. Value construction and move construction transfer ownership
of a completed payload, while destruction and `reset()` drop an engaged value
exactly once.

Allocation-free describes the optional slot. Constructing `T` can still report
its ordinary `allocation_failure` / `element_construction` outcome. Because
`emplace()` resets first, failed payload construction leaves the optional empty.

`value()`, `operator*`, and `operator->` return receiver-tied references.
Accessing an empty optional raises GTI's checked `GTI-R0008` owner failure after
ordinary scope cleanup. A live returned reference prevents reset, emplacement,
or movement of the owner until the borrow ends.

The current optional is move-only even when `T` is copyable. Copy construction,
copy assignment, and move assignment are unavailable; use `reset()` or
`emplace()` to replace a value. `value_or(fallback)` copies an engaged value and
therefore instantiates only for payloads whose ordinary copy is valid. There is
no public `nullopt` sentinel in this first slice; `{}` constructs the empty
state.
