```gti
#include <std/algorithm>
```

The iterator-pair algorithms consume their cursor values and use structural
iterator concepts from `<std/iterator>`. They do not use C++ iterator-category
dispatch, implicit conversions, or argument-dependent lookup.

`copy` advances a mutable output cursor but returns `void`: a mutable
owner-tied cursor cannot currently escape through the return value. The
in-place `fill`, `transform`, `reverse`, and `sort` overloads operate on
`std::vector<T>` owners so one exclusive borrow covers the complete rewrite.
Those overloads require copyable elements; they do not move values out through
mutable references.

`binary_search` accepts a forward iterator and a distinct sentinel. It counts
the range before searching and therefore remains valid for non-random-access
forward ranges.
