```gti
#include <std/tcp>
```

This bounded POSIX-only API opens an unconnected IPv4 stream socket. It does
not yet expose addresses, `connect`, `accept`, sending, receiving, or the
native descriptor.

The socket is move-only. `close()` reports recoverable errors and invalidates
the owner exactly once; destruction performs best-effort close when needed.
Importing this unit is rejected on Windows and unknown targets.
