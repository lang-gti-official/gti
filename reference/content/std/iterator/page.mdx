```gti
#include <std/iterator>
```

Iterator behavior is structural. The category concepts test exact operator
and lifecycle capabilities; the tag structs are familiar vocabulary and do
not drive compiler dispatch.

Unsigned movement works with input iterators. Signed `advance` and `prev`
require bidirectional movement, while signed `next` uses the random-access
`+=` capability. `distance` walks an input iterator until its compatible
sentinel and returns `std::ptrdiff_t`.
