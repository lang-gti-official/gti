```gti
#include <std/cstdio>
```

This is a bounded, unbuffered input API rather than a complete C stdio
implementation. `std::getchar` and `std::fgetc` read one byte and report EOF
or host failures through `expected`. `std::fopen` supports only `"r"` and
`"rb"` and returns a `std::unique_ptr<std::FILE>`.

`std::FILE` owns the native handle and closes it exactly once. Explicit
`close()` reports failure; destruction performs best-effort cleanup when the
stream is still open. The adopting constructor is available to trusted
standard-library code through its compiler-private handle parameter and is
not an application construction route.
