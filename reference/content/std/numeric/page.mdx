```gti
#include <std/numeric>
```

The wrapping, saturating, and checked families cover every fixed-width signed
and unsigned integer type. Checked arithmetic returns
`expected<T, std::arithmetic_errc>` instead of invoking undefined behavior or
silently changing overflow policy.

`gcd`, `lcm`, and `midpoint` are constrained integral utilities. `accumulate`,
`inner_product`, and `transform_reduce` consume structural input iterators and
exact callables. The `lerp` overload family includes built-in floating-point
arithmetic and source-defined vector-space values.

Primitive hash specializations are not part of the supported API even though
latent source declarations remain in this unit.
