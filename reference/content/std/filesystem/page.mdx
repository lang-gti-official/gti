```gti
#include <std/filesystem>
```

`std::filesystem::path` performs pathname manipulation only. It does not read
directories, query files, canonicalize against a filesystem, or expose native
handles.

Construction preserves the supplied spelling. `lexically_normal()` is the
explicit operation that resolves redundant separators and dot elements.
Directory joining is available through `/`, `/=`, `append`, and
`append_path`; `concat` adds text without inserting a separator. An absolute
right operand replaces the left path.

The owner is move-only and independent duplication is explicit through
`clone()`. Decomposition functions return new `path` owners. `string()`
returns a new `std::string` containing the native spelling.
