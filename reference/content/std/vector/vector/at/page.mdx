---
title: std::vector::at
description: Performs checked indexed access and returns an element borrow.
kind: member
since: 0.80.0
api:
  - std/vector|method|std::vector::at
examples:
  - checked-index-access
---

Returns the element at `index`. Both the read-only and mutable overloads check
the index against the logical vector size.

An out-of-range index follows GTI's defined bounds-failure path. Mutable access
returns `mut T&`, tying the resulting loan to the vector until the borrow ends.

Unlike C++, GTI's `operator[]` is checked as well. Choose `at()` when the named
operation makes the bounds-sensitive intent clearer.
