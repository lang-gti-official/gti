---
title: std::vector::pop_back
description: Removes and destroys the final element when one is present.
kind: member
since: 0.80.0
api:
  - std/vector|method|std::vector::pop_back
examples:
  - remove-the-last-element
---

Destroys the final element and decreases `size()` by one. Existing capacity is
retained for later insertions.

Calling `pop_back()` on an empty vector is a no-op in the current GTI API. The
operation does not return the removed value.
