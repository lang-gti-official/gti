---
title: std::vector::end
description: Returns the sentinel marking the end of vector traversal.
kind: member
since: 0.80.0
api:
  - std/vector|method|std::vector::end
examples:
  - stop-at-the-sentinel
---

Returns a sentinel containing the current logical end position. Read-only and
mutable range loops compare their iterator with this sentinel to decide when
traversal is complete.

The sentinel is a boundary value, not an element iterator, and cannot be
dereferenced. Range syntax obtains it automatically.
