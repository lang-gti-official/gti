---
title: std::vector::push_back
description: Appends one value to the end of the vector, consuming the argument as required.
kind: member
since: 0.80.0
api:
  - std/vector|method|std::vector::push_back
examples:
  - append-values
---

Appends `value` after the current final element. The vector grows its allocation
when no spare capacity remains.

The parameter is passed by value. Copyable lvalues may be copied; a move-only
value must be transferred explicitly with `std::move`. The operation returns
`void`; use `emplace_back()` when construction in the final slot and a borrow
of the new element are required.
