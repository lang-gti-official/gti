---
title: std::vector::insert
description: Inserts one value at a checked numeric position and shifts later elements right.
kind: member
since: 0.139.0
api:
  - std/vector|method|std::vector::insert
examples:
  - insert-in-the-middle
---

Inserts `value` at `index`, preserving the order of the elements already at and
after that position. This initial GTI API accepts a numeric index rather than
an iterator position.

The vector may grow before insertion. The value parameter is consumed according
to its type, so move-only lvalues require `std::move`. Existing element and
iterator loans must end before the operation.
