The standard-library declaration reserves the intended operation for
exchanging the contents of two mutable vectors.

> `swap()` does not yet have a GTI library body. A native program that calls it
> will fail during linking, so this page intentionally has no copyable example.

Once implemented, the operation must exchange ownership without copying
elements and must reject incompatible outstanding loans on either vector. Its
published behavior will be expanded here only when the compiler-verified
implementation exists.
