`std::vector<T>` owns a dynamically sized, contiguous sequence. `T` must
satisfy `std::movable` and must not retain borrowed state. The vector itself is
move-only even when its elements are copyable.

Select any constructor or member name in the synopsis for its exact overloads,
operation-specific rules, and a compiler-verified example where the operation
is currently callable.

## Construction

The default constructor creates an empty vector. `vector(n)` creates `n`
value-initialized elements; it is not a reserve-only constructor. A contextual
fixed array can provide initial values:

```gti
mut std::vector<int32_t> values =
    std::vector<int32_t>({4, 7, 9});
```

Copy construction is deleted. Transfer an existing vector explicitly with
`std::move`, or call `clone()` when `T` is copyable and an independent copy is
required.

## Element access

Both `at(index)` and `operator[](index)` check the logical vector size. An
invalid index follows GTI's defined storage-failure path; there is no unchecked
subscript operation on this initial safe API.

Read-only receivers return `T&`. Mutable receivers return `mut T&`, and that
borrow prevents an overlapping operation that could move or reallocate the
vector until the borrow ends.

## Capacity and modification

`reserve` grows capacity without changing size. `resize` changes the number of
live elements, while `shrink_to_fit` reduces spare storage. `push_back`,
`insert`, and `emplace_back` consume values as required by their parameter
types and preserve deterministic cleanup.

`emplace_back(args...)` constructs the element in its final slot and returns a
receiver-tied mutable borrow. It is in-place construction, but it does not
promise C++ perfect-forwarding behavior.

## Iteration

An ordinary range loop uses the read-only iterator. A mutable range loop uses
the separate `begin_mut()` path and holds one exclusive parent loan for the
vector. Capacity changes, movement, and other overlapping mutable operations
are rejected while that traversal is active.

## Current limitations

Iterator-position insertion and erasure, allocator policy, retained cursors,
and owner-tied spans are not implemented. `swap` is currently declared as API
scaffolding but has no library body, so using it in a native build will fail to
link until that implementation lands.
