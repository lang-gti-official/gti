Returns the element capacity of the current allocation. `capacity()` is always
at least `size()`; the difference is spare storage available to later
insertions.

Capacity-changing operations may relocate elements. GTI rejects such an
operation while an incompatible element or iterator loan is live.

## Return value

The number of elements that fit without another allocation.
