---
title: std::vector::reserve
description: Ensures storage for a requested number of elements without changing the size.
kind: member
since: 0.80.0
api:
  - std/vector|method|std::vector::reserve
examples:
  - reserve-before-appending
---

Ensures that `capacity()` is at least `requested`. If the current capacity is
already sufficient, the call has no effect. Otherwise the vector relocates its
elements into a larger allocation while preserving their order.

`reserve()` never constructs or removes elements, so `size()` is unchanged.
The operation requires a mutable receiver and is rejected while an
incompatible element or iterator loan is live.
