---
title: std::vector::emplace_back
description: Constructs an element in the final slot and returns an owner-tied mutable borrow.
kind: member
since: 0.80.0
api:
  - std/vector|method|std::vector::emplace_back
examples:
  - construct-a-record
---

Constructs a `T` directly in the new final slot from `args...`. The vector may
grow before construction.

The returned `mut T&` is tied to the vector. While that borrow is live, another
operation that could mutate, move, or reallocate the vector is rejected. End
the borrow's scope before appending again.

This is GTI's in-place construction API; it does not promise C++
perfect-forwarding semantics.
