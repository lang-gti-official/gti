---
title: std::vector::front
description: Borrows the first element through a read-only or mutable receiver.
kind: member
since: 0.120.0
api:
  - std/vector|method|std::vector::front
examples:
  - read-and-update-front
---

Returns a borrow of the first element. A read-only receiver produces `T&`; a
mutable receiver can produce `mut T&` for in-place modification.

The vector must not be empty. Calling `front()` on an empty vector follows
GTI's defined bounds-failure path rather than yielding an invalid reference.

The returned borrow is tied to the vector and prevents overlapping movement or
storage reallocation while it remains live.
