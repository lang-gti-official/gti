---
title: std::vector::erase
description: Removes the element at a checked numeric position and closes the gap.
kind: member
since: 0.139.0
api:
  - std/vector|method|std::vector::erase
examples:
  - erase-from-the-middle
---

Destroys the element at `index`, shifts later elements left, and decreases
`size()` by one. The operation accepts a numeric index; iterator-range erasure
is not part of the current API.

The index is checked against the logical vector size. Capacity is retained,
and existing element or iterator loans must end before erasure.
