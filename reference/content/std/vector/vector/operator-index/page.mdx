---
title: std::vector::operator[]
description: Performs concise checked indexed access and returns an element borrow.
kind: member
since: 0.80.0
api:
  - std/vector|operator|std::vector::operator[]
examples:
  - subscript-access
---

Returns the element at `index` through subscript syntax. GTI deliberately
checks this operation against `size()`; it does not inherit C++'s unchecked
`std::vector::operator[]` behavior.

Read-only access returns `T&`. A mutable vector can return `mut T&`, with the
same owner-tied loan rules as `at()`.
