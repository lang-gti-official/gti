---
title: std::vector::clone
description: Creates an independent element-wise copy when the element type is copyable.
kind: member
since: 0.105.0
api:
  - std/vector|method|std::vector::clone
examples:
  - clone-independently
---

Returns a new vector containing copies of the current elements. The operation
is available only when `T` satisfies `std::copyable`.

The result owns independent storage. Mutating the clone does not change the
source vector. This explicit operation replaces implicit vector copy
construction, which is deleted even for copyable element types.
