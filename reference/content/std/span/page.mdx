```gti
#include <std/span>
```

`std::span<T>` is a read-only, owner-dependent view. Applications obtain one
from source-defined owners such as `std::vector<T>::as_span()` and
`std::string::as_span()`; its storage-adopting constructor is not available to
application lookup.

Every index and subspan boundary is checked. The span keeps its source owner
borrowed, preventing movement or mutation of that owner while the view remains
live. `first`, `last`, and `subspan` return new views with the same owner
dependency, and iteration retains that dependency as well.
