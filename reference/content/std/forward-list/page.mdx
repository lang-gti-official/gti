```gti
#include <std/forward_list>
```

The implemented slice owns a recursive `std::unique_ptr` node chain and
provides constant-time insertion, removal, and access at the front. The list
is move-only and deterministic destruction clears the complete chain.

Iteration and the remaining C++-familiar declarations in the source unit are
currently scaffolds. They are intentionally absent from this executable API
synopsis.
