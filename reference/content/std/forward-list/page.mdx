```gti
#include <std/forward_list>
```

The list owns an exclusive `std::unique_ptr` node chain and provides
constant-time insertion, removal, and access at the front. Clear and
destruction drain the chain iteratively.

Reverse, removal, adjacent uniqueness, and sorted merge are linear. Sort is
stable bottom-up mergesort with O(n log n) comparisons. These operations
relink node owners without allocating nodes or copying or moving elements.
Merge consumes its other list; both inputs must already be sorted. Equal
elements from the receiving list stay before equal elements from the other
list. Unique keeps the first element of each adjacent equal run. Remove and
unique return the number removed.

Resize preserves the existing prefix and constructs only added elements,
using either default construction or copies of its fill value.

Swap exchanges node chains in constant time without allocation or element
movement. Both lists must be mutable and distinct, with no live element borrow.

Iteration and emplacement remain declaration-only scaffolds and are
intentionally absent from this executable API synopsis.
