---
title: Direct compilation
description: Compile one GTI entry source, inspect intermediate artifacts, or forward bounded native arguments.
kind: command
api: []
examples: []
---

```sh
gti source.gti [options] [-- native-compiler-arguments]
```

The source and every GTI include form one whole program. Direct mode does not
discover `gti.toml` and does not resolve package dependencies.

## Common outputs

```sh
gti src/main.gti -O2 -o app
gti src/main.gti --emit-cpp -o generated.cpp
gti src/main.gti --emit-mir -o program.mir
```

`--keep-cpp` retains generated C++ beside an executable build. `--emit-cpp`
and `--emit-mir` emit an artifact instead of linking an executable.

## Analysis and optimization controls

- `-O0` through `-O3` select the GTI and native optimization level.
- `-D NAME` defines a valueless GTI configuration flag.
- `--execution-profile single-threaded|concurrent` selects the global
  execution policy. Managed threads require `concurrent`.
- `--time-trace path` writes a Chrome Trace compile-time profile.
- `--dump-mir-before`, `--dump-mir-after`, optimization remarks, and the
  optimization report expose verified MIR decisions for investigation.

Arguments after `--` are forwarded as exact native compiler arguments, subject
to the driver's safety policy. They do not define GTI configuration flags and
must not replace outputs, target policy, language mode, or other
driver-controlled build facts.
