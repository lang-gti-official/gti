The language server provides whole-document formatting. It searches from the
source file toward the filesystem root and applies the nearest `.gti-format`.

Create the compiler-owned default configuration with:

```sh
gti format init
gti format init path/to/project
```

The initializer requires an existing real directory and refuses to overwrite
an existing configuration.

GTI intentionally reuses clang-format option names only where their meaning is
implemented. `BasedOnStyle`, indentation, brace style, pointer/reference
alignment, spaces around operators, include-block spacing, short-function
policy, and `requires` clause placement are among the supported controls.
Unknown or unsupported keys are diagnostics; they are not silently accepted as
future promises.

The formatter is recovery-oriented so incomplete editor buffers can still be
formatted, but the compiler remains responsible for deciding whether the
source is valid GTI.
