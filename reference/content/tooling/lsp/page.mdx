`gti_lsp` speaks the Language Server Protocol over standard input and output.
Editors normally start it through their LSP configuration rather than as an
interactive command.

## Implemented capabilities

- full document synchronization and compiler diagnostics;
- semantic tokens;
- hover and signature help with resolved overload and generic information;
- completion;
- go to definition, references, and document highlights;
- document symbols and rename;
- mechanically safe diagnostic code actions; and
- whole-document formatting using `.gti-format`.

The server analyzes immutable frontend snapshots. Open dirty buffers override
disk contents, dependency edits invalidate affected dependants, superseded
generations are rejected, and UTF-16 protocol positions are converted at the
boundary. Compiler semantics remain the authority for symbols, types,
overloads, ownership facts, and diagnostics.

## Current scope

References and rename are complete for the loaded source graph; they are not a
repository-wide background index. The server does not run the C++ backend or
native linker, and it does not invent results for source excluded by active
configuration. Project discovery supplies manifest configuration for the
active package, while broader workspace indexing remains future work.
