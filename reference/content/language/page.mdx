## How this reference is organized

Language pages explain the concepts needed to read and write GTI. Library pages
document one header, type, function, or member at a time, with declarations
projected from the compiler rather than reconstructed from source text.

Examples belong to the page that teaches the API. They are compiled as
independent GTI programs, so a focused library page can demonstrate its own
contract without inheriting assumptions from the repository's broader example
suite.

This landing page intentionally stays at overview level while the compiler data
and content-verification foundation is established.
