# Plan A GTI Feature — Claude Client

Read [the canonical planning skill](../../../.codex/skills/plan-feature/SKILL.md)
completely before drafting. It owns request routing, the RFC repository's
generator/template, draft publication, document checks, and decision boundaries.
Use Claude's Skill tool or `/<skill-name>` where it names a Codex `$skill`.

The owner's standing instruction authorizes a draft RFC and draft proposal PR
in `lang-gti-official/rfcs` when asked to plan a new feature. Honor explicit
publication restrictions. Do not register a compiler implementation task,
merge the proposal, accept its design, or implement it from a planning request.
Keep the RFC repository's own instructions and validation separate from the
compiler lifecycle; report the RFC and proposal PR links and open questions.
