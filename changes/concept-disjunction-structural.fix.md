Generic bodies can now satisfy a disjunctive concept for a type built from a constrained parameter, such as `Node<T>` under `std::relocatable<T> || has_borrowed<T>()`: each alternative's compiler-verified fact, including a wrapper's negated `!std::meta::is_borrow_free<T>()`, carries through fields that store the parameter by value. Pointer and reference fields, removed special members and opaque predicates still yield no proof.
