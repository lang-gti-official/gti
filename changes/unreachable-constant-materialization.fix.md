Fix an internal compiler error (GTI-B0001, "program-constant substitution has no exact MIR materialization") when unreachable code reads a program constant, such as `std::println("{}", 3)` after `return`, or a `constexpr` name after `break`, `continue`, a never-returning call or a never-returning operand. Unreachable code now compiles under both execution profiles, and reachable constant reads are unchanged.
