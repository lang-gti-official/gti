Reading or writing a field of a reference stored in an enum payload (such as `value.y` after `case Reading::item(value)`), and binding a borrowed-carrier reference through a raw-pointer dereference in `unsafe` code (`View& r = *p;`), no longer stop with an internal compiler error (GTI-B0001). A write to the payload's owner while such a field is still read is rejected with GTI-S2017.
