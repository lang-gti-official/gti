Fix an internal compiler error (GTI-B0001, "program-constant substitution has no exact MIR materialization") when a parenthesized `constexpr` name, such as `1.0 * (SPEED)`, `twice((SPEED))` or `v * (SPEED)` with a user-defined operator, is read as a value. Grouped and comma-ended reads of a program constant now read its constant value in every value context, under both execution profiles.
