A read-only `operator*` may now yield a copyable value that carries borrowed state, such as `std::span<int, owner>` or an application view type, when every region in its signature is one of the iterator class's own lifetime parameters: the value borrows what the cursor stores rather than the cursor, so it stays valid after `++`, works as a range-for loop variable by value or by reference, and the cursor satisfies `std::input_iterator` and `std::forward_iterator`. `std::meta::method` gains `result_outlives_receiver()`. Yields that borrow the cursor itself, and `string_view`/`c_string` yields, are still rejected (GTI-S2022).
