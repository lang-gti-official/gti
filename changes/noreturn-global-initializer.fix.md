Calling a `[[noreturn]]` function in a namespace global or class static field initializer, directly, as an operand such as `1 + die()`, or in a selected conditional arm, no longer fails with an internal compiler error ("body lowering rejected its checked HIR before program initialization"). The program compiles and terminates during program initialization through the normal panic containment, cleaning up earlier globals; a conditional whose other arm is selected initializes normally. Declarations after such an initializer, and statements after a function-local `static`, no longer receive a spurious `GTI-S2095` unreachable-code warning.
