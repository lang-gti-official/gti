Two patterns no longer fail with an internal compiler error ("failed to construct valid MIR"). The first is a read-only range-`for` over records that contain a static span, such as `for (auto& entry : descriptors)`. The second is a local text view that holds a literal and is conditionally reassigned to a view of a shared-reference parameter. After the branch, the local view depends on both possible owners, so a conflicting mutation is still rejected.
